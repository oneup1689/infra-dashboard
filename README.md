# infra-dashboard — веб-морда монитора балансов (для телефона)

Это **только страница** для просмотра балансов. Здесь нет ни кода монитора, ни ключей —
поэтому репозиторий можно сделать публичным и открывать страницу с телефона как приложение.
Какие балансы показывать — задаётся топиком ntfy, который вводится на самом телефоне (в настройках ⚙︎)
и хранится только в браузере.

Данные страница берёт из топика **DATA** в ntfy (его наполняет монитор из репозитория `infra-monitor`).

## Публикация и включение GitHub Pages

1. **GitHub Desktop → File → Add local repository →** указать папку этого репозитория → **Add**.
2. Кнопка **Publish repository**. Имя — `infra-dashboard`.
   **Снять** галочку «Keep this code private» (репозиторий должен быть **публичным** — иначе бесплатный
   Pages не работает). **Publish**.
3. На github.com открыть репозиторий → **Settings** → слева **Pages**.
4. **Source:** «Deploy from a branch». **Branch:** `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты вверху появится адрес: `https://ТВОЙ_ЛОГИН.github.io/infra-dashboard/`.

## На телефоне

1. Открыть этот адрес в браузере телефона.
2. Меню браузера → **«Добавить на главный экран»** — появится иконка, страница открывается как приложение.
3. Нажать ⚙︎ и вписать:
   - **Топик DATA:** тот же `infra-data-…`, что в секрете `NTFY_TOPIC_DATA`;
   - **Репозиторий монитора:** можно оставить пустым (по умолчанию `oneup1689/infra-monitor`);
   - **GitHub-токен** — см. ниже.
4. Кнопка **«Проверить сейчас»** сама запускает прогон монитора; через ~минуту морда обновится.
   Без токена кнопка только открывает страницу Actions на GitHub, а там нужен вход в аккаунт:
   репозиторий приватный, без входа будет 404.

## Токен для «Проверить сейчас» (один раз)

1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens →
   Generate new token**.
2. **Name:** `infra-dashboard run`. **Expiration:** 1 год, ставим напоминание перевыпустить.
3. **Repository access:** *Only select repositories* → `infra-monitor`.
4. **Permissions → Repository permissions → Actions:** *Read and write*. Больше ничего не включать.
5. **Generate token**, скопировать значение и вставить в ⚙︎ → «GitHub-токен» на телефоне. Никуда больше его не пересылать.

Такой токен умеет только запускать и смотреть прогоны в `infra-monitor`: ни кода, ни секретов он не видит.
Хранится он только в браузере телефона.

## Обновление дизайна

Страница правится только в `infra_monitor/dashboard/index.html`. Копировать сюда — командой
`python sync_dashboard.py` из папки `infra_monitor`, руками этот файл не править.
